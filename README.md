# WEB_assignment_6

Student: **Amerkhanova Aruzhan**  
Group: **SE-2529**

A simple five-page assignment demonstrating jQuery selectors, effects, DOM manipulation and animations. The mini project is a nature image gallery.

## Pages

| Page | Tasks |
| --- | --- |
| Part 1 (index.html) | 0–1: CDN setup, ready callback, selectors, text, HTML and CSS |
| Part 2 (part2.html) | 2–4: visibility, fade and slide effects |
| Part 3 (part3.html) | 5–7: list changes, image/link attributes and live form input |
| Part 4 (part4.html) | 8–10: basic, sequential and combined animations |
| Part 5 (part5.html) | 11: fading thumbnails and an enlarged image viewer |

## Run locally

Open the project folder in IntelliJ IDEA, then open index.html in a browser. You can also open index.html directly. No installation or build is needed. An internet connection is required to load the full jQuery 3.7.1 library from https://code.jquery.com/jquery-3.7.1.min.js.

Use the navbar to move between parts. In Part 1, open the browser console to see "jQuery is ready!". In the gallery, click a thumbnail to enlarge it; use Close, Escape or the backdrop to close it.
